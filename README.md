# custom-collector-framework
Instana's Python Custom Collector Framework.

The Custom Collector Framework provides the runtime, packaging,
configuration, execution, and management model for customer-developed business
metric collectors.

The framework is composed by:

- IBM-maintained Python runtime
- IBM-maintained Python base library
- Container-based execution on Linux VMs
- Supervisor-managed lifecycle
- Backend-driven configuration and work assignment
- Multi-endpoint runtime handling
- API-based extension and deployment management

This gives the customer a structured way to run customer-developed collection
logic within the Instana solution.
